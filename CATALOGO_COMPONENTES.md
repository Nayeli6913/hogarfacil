# Catálogo de Componentes - HogarFácil

## 1. AppButton
Propósito:
Botón reutilizable para acciones principales.

Entradas:
- text (obligatorio)
- onPressed (obligatorio)
- loading (opcional)

## 2. AppTextField
Propósito:
Campo de texto reutilizable.

Entradas:
- controller
- label
- icon
- hint
- validator
- obscureText

## 3. LoadingView
Propósito:
Mostrar un indicador de carga mientras se espera una respuesta.

Entradas:
- loading
- child
